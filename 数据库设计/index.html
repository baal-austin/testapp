数据库设计

数据库表功能与属性详细描述

​ ​

核心部分：

  1. ​用户管理​：用户基本信息、设置和学习统计

  2. ​单词管理​：单词核心信息、释义、例句、词形变化和发音

  3. ​分类与标签​：单词的分类和标签系统

  4. ​单词关系​：单词间的多种关系类型

  5. ​学习管理​：单词列表、学习计划、进度跟踪和复习计划

  6. ​测试评估​：测验系统及相关结果跟踪

  7. ​用户贡献​：用户提交的内容修改建议

用户相关表

1. User（用户表）

​功能​：存储系统用户的基本信息 ​属性​：

  • ​id：主键，用户唯一标识符

  • ​username：用户名，用于登录和显示

  • ​email：用户邮箱，用于登录和通知

  • ​phone：电话号码，用于登录和通知

  • ​qq：QQ号，用于登录和通知

  • ​wx：微信号，用于登录和通知

  • ​hashed_password：加密后的密码

  • ​display_name：用户显示名称，可不同于用户名

  • ​avatar：用户头像URL或路径

  • ​created_at：账户创建时间

  • ​last_login：最后登录时间

  • ​is_active：账户是否激活

  • ​is_premium：是否为高级会员

  • ​streak_days：连续学习天数

  • ​total_words_learned：已学习的单词总数

2. UserSetting（用户设置表）

​功能​：存储用户的个性化设置 ​属性​：

  • ​id：主键，设置唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​study_daily_goal：每日学习目标单词数量

  • ​review_daily_goal：每日复习目标单词数量

  • ​notification_enabled：是否启用通知

  • ​notification_time：每日提醒时间

  • ​study_reminders：是否启用学习提醒

  • ​language：界面语言代码

  • ​pronunciation_accent：偏好发音口音(us/uk等)

3. UserStatistic（用户统计表）

​功能​：记录用户每日学习统计数据 ​属性​：

  • ​id：主键，统计记录唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​date：统计日期

  • ​words_studied：当日学习的单词数量

  • ​time_studied：当日学习时长(分钟)

  • ​correct_answers：当日正确答题数量

  • ​incorrect_answers：当日错误答题数量

单词管理相关表

4. Word（单词表）

​功能​：存储单词核心信息 ​属性​：

  • ​id：主键，单词唯一标识符

  • ​word：单词原文

  • ​normalized_word：标准化后的单词(小写形式，便于搜索)

  • ​length：单词长度(字符数)

  • ​frequency_rank：词频排名，数值越小表示越常见

  • ​difficulty_level：难度等级(1-5)

  • ​is_common：是否为常用词

  • ​tags_json：单词标签的JSON字符串

  • ​etymology：词源信息

  • ​created_at：单词添加时间

  • ​updated_at：单词更新时间

  • ​description：单词描述

  • audio_url：发音音频链接

  • 浏览数

5. WordDefinition（单词释义表）

​功能​：存储单词的多种释义 ​属性​：

  • ​id：主键，释义唯一标识符

  • ​word_id：外键，关联的单词ID

  • ​part_of_speech：词性

  • ​definition：英文释义

  • ​definition_cn：中文释义

  • ​order：释义显示顺序(同一单词可能有多个释义)

  • ​domains_json：适用领域的JSON字符串(如:医学,法律,计算机等)

  • ​example_usage：用法示例

6. Example（例句表）

​功能​：存储单词的例句 ​属性​：

  • ​id：主键，例句唯一标识符，例句ID

  • ​sentence：例句原文

  • ​translation：例句翻译

  • ​source：例句来源(如词典名称、文学作品等)

  • ​context：例句上下文信息

  • created_at ：创建时间

  • updated_at ：更新时间

7. WordForm（词形变化表）

​功能​：存储单词的各种形式变化 ​属性​：

  • ​id：主键，单词形式唯一标识符，变化ID

  • ​word_id：外键，关联的单词ID

  • ​form_type：形式类型(复数、过去式等) ENUM( 'BASE_FORM', 'THIRD_PERSON', 'PAST_TENSE', 'PAST_PARTICIPLE', 'PRESENT_PARTICIPLE', 'PLURAL_FORM', 'COMPARATIVE', 'SUPERLATIVE', 'POSSESSIVE' )

  • ​form_word：变形后的单词

  • created_at ：创建时间

分类与标签表

10. Tag（标签表）

​功能​：存储单词标签 ​属性​：

  • ​id：主键，标签唯一标识符

  • ​name：标签名称(如:雅思,托福,GRE,四六级等)

11. WordTag（单词标签关联表）

​功能​：建立单词与标签的多对多关系 ​属性​：

  • ​id：主键，单词标签关联唯一标识符

  • ​word_id：外键，关联的单词ID

  • ​tag_id：外键，关联的标签ID

12. Category（分类表）

​功能​：存储单词分类 ​属性​：

  • ​id：主键，分类唯一标识符

  • ​name：分类名称(如:日常用语,商务英语,科技,医学等)

  • ​parent_id：外键，父分类ID(用于层级分类)

13. WordCategory（单词分类关联表）

​功能​：建立单词与分类的多对多关系 ​属性​：

  • ​id：主键，单词分类关联唯一标识符

  • ​word_id：外键，关联的单词ID

  • ​category_id：外键，关联的分类ID

单词关系表

14. WordRelation（单词关系表）

功能：存储单词之间的关系 属性：

  • ​id：主键，关系唯一标识符，关系ID

  • ​source_id：外键，源单词ID

  • ​target_id：外键，目标单词ID

  • ​created_at：关系创建时间

  • ​updated_at ：关系更新时间

（两个单词之间只有一条关系边）

‍

14. RelationType（关系类型表）

功能：存储单词之间的各种关系类型 属性：

  • ​id：主键，关系唯一标识符，关系类型ID

  • ​type_name：关系类型名称

  • ​category：关系类别，'semantic', 'formal', 'morphological', 'associative'

  • ​description：关系类型描述

  • created_at：创建时间

‍

14. RelationTypeMapping（关系类型映射表）

​功能​：存储单词之间的各种关系 ​属性​：

  • ​id：主键，关系映射唯一标识符，映射ID

  • ​relation_id ：关系ID，外键

  • relation_type_id ：关系类型ID，外键

  • ​official_strength：官方关系强度(0-1)

  • ​official_description ：官方关系描述

  • created_at：创建时间

  • updated_at：更新时间

（一条关系可以对应多个类型）

‍

学习管理表

15. WordList（单词列表表）

​功能​：存储用户创建的单词列表 ​属性​：

  • ​id：主键，单词列表唯一标识符

  • ​user_id：外键，创建者用户ID

  • ​name：单词列表名称

  • ​description：单词列表描述

  • ​is_public：是否公开(其他用户可见)

  • ​created_at：列表创建时间

  • ​word_count：列表中单词数量

‍

15. Notes（统一笔记表）

​功能​：存储用户创建的各种类型笔记（单词笔记、关系笔记、关系类型笔记）

​属性​：

  • ​id：主键，笔记唯一标识符

  • ​user_id：外键，创建者用户ID

  • ​word_id：外键，关联单词ID（可选）

  • ​relation_type_mapping_id：外键，关系类型映射ID（可选）

  • ​title：笔记标题

  • ​content：笔记内容

  • ​note_type：笔记类型（word/relation/relation_type）

  • ​strength：用户自定义关系强度（仅对关系笔记有效）

  • ​tags：标签数组（JSON格式）

  • ​is_public：是否公开(其他用户可见)

  • ​likes：点赞数

  • ​views：浏览数

  • ​status：审核状态（pending/approved/rejected）

  • ​created_at：笔记创建时间

  • ​updated_at：笔记更新时间

    ‍

16. WordListItem（单词列表项表）

​功能​：存储单词列表中的单词项 ​属性​：

  • ​id：主键，列表项唯一标识符

  • ​word_list_id：外键，关联的单词列表ID

  • ​word_id：外键，关联的单词ID

  • ​added_at：单词添加到列表的时间

  • ​order：在列表中的显示顺序

17. StudyPlan（学习计划表）

​功能​：存储用户的学习计划 ​属性​：

  • ​id：主键，学习计划唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​name：学习计划名称

  • ​description：学习计划描述

  • ​word_list_id：外键，关联的单词列表ID

  • ​daily_target：每日目标学习单词数量

  • ​start_date：计划开始日期

  • ​end_date：计划结束日期(可选)

  • ​is_active：计划是否激活

18. UserWordProgress（用户单词进度表）

​功能​：跟踪用户对每个单词的学习进度 ​属性​：

  • ​id：主键，学习进度唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​word_id：外键，关联的单词ID

  • ​status：学习状态(new, learning, reviewing, mastered)

  • ​familiarity：熟悉程度(0-100)

  • ​last_studied：最后学习时间

  • ​next_review：下次复习时间

  • ​study_count：学习次数

  • ​correct_count：答题正确次数

  • ​wrong_count：答题错误次数

  • ​ease_factor：间隔重复算法中的易度因子

  • ​interval：下次复习间隔(天)

  • ​due_date：计划复习日期

19. StudySession（学习会话表）

​功能​：记录用户的学习会话 ​属性​：

  • ​id：主键，学习会话唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​start_time：会话开始时间

  • ​end_time：会话结束时间

  • ​duration：会话持续时间(秒)

  • ​words_studied：本次会话学习的单词数量

  • ​session_type：会话类型(learn, review, test等)

20. ReviewSchedule（复习计划表）

​功能​：安排用户的单词复习计划 ​属性​：

  • ​id：主键，复习计划唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​word_id：外键，关联的单词ID

  • ​due_date：计划复习日期

  • ​completed：是否已完成复习

  • ​completed_at：完成复习的时间

测试评估表

21. Quiz（测试表）

​功能​：存储测试的基本信息 ​属性​：

  • ​id：主键，测试唯一标识符

  • ​name：测试名称

  • ​description：测试描述

  • ​quiz_type：测试类型(multiple_choice, spelling, matching等)

  • ​difficulty：测试难度(easy, medium, hard)

  • ​time_limit：时间限制(秒)

22. QuizQuestion（测试问题表）

​功能​：存储测试题目 ​属性​：

  • ​id：主键，测试题目唯一标识符

  • ​quiz_id：外键，关联的测试ID

  • ​question_text：题目文本

  • ​question_type：题目类型(definition, synonym, antonym, usage等)

  • ​options：选项(JSON格式存储)

  • ​correct_answer：正确答案

  • ​explanation：答案解析

23. QuizAttempt（测试尝试表）

​功能​：记录用户尝试测试的情况 ​属性​：

  • ​id：主键，测试尝试唯一标识符

  • ​user_id：外键，关联的用户ID

  • ​quiz_id：外键，关联的测试ID

  • ​start_time：开始时间

  • ​end_time：结束时间

  • ​score：得分(百分比)

  • ​total_questions：总题目数

  • ​correct_answers：答对题目数

24. QuizResult（测试结果表）

​功能​：存储用户测试的详细结果 ​属性​：

  • ​id：主键，测试结果唯一标识符

  • ​quiz_attempt_id：外键，关联的测试尝试ID

  • ​question_id：外键，关联的题目ID

  • ​user_answer：用户答案

  • ​is_correct：答案是否正确

  • ​time_taken：答题耗时(秒)

用户贡献表

25. UserContribution（用户贡献表）

​功能​：记录用户提交的内容修改建议 ​属性​：

  • ​id：主键，贡献记录唯一标识符

  • ​type：贡献类型(add_word, update_word, add_relation, update_relation)

  • ​data：JSON字段，存储提交的详细数据

  • ​status：审核状态(pending, approved, rejected)

  • ​submitted_by：外键，提交者ID

  • ​submitted_at：提交时间

  • ​reviewed_by：外键，审核人ID

  • ​reviewed_at：审核时间

  • ​feedback：审核反馈

‍

Wordbooks（词库表）

​功能​：存储用户创建或系统预定义的词库集合

​属性​：

  • ​id：主键，词库唯一标识符

  • ​name：词库名称（必填）

  • ​creator_id：外键，创建者用户ID（必填）

  • ​is_public：是否公开（默认私有）

  • ​likes：点赞数统计（默认0）

  • ​tags：标签数组（JSON格式存储）

  • ​created_at：词库创建时间（自动记录）

  • ​updated_at：词库最后更新时间（自动更新）

‍

Wordbook_Words（词库单词关联表）

​功能​：维护词库与单词的多对多关联关系

​属性​：

  • ​id：主键，关联记录唯一标识符

  • ​wordbook_id：外键，所属词库ID（必填）

  • ​word_id：外键，关联单词ID（必填）

  • ​added_at：单词加入词库的时间（自动记录）

总结

这个数据库设计支持了一个完整的单词学习系统，涵盖了用户管理、单词管理、学习进度跟踪、测试评估和社区贡献等功能。表之间的关系设计合理，支持系统的核心功能需求，包括：

  1. 多维度单词管理（释义、例句、发音、词形变化）

  2. 复杂的单词关系网络

  3. 个性化学习计划和进度跟踪

  4. 间隔重复算法的实现

  5. 测试评估和学习效果分析

  6. 用户贡献和社区协作机制

这种设计能够支持您之前描述的所有核心功能，并为未来的功能扩展提供了良好的基础。
